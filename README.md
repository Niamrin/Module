# Конструктор курса — Vue 3

Версия 2.0.0. Vue 3.5.13, Composition API, JavaScript, Vite. Компоненты с шаблонами в JS (не SFC), без UI-библиотеки, без серверной части.

## Быстрый запуск
Откройте `public/course_builder_vue3.html` в современном браузере. Vue встроен в файл; интернет для самого редактора не нужен. Для внешних изображений и видео нужен доступ к соответствующему источнику. Некоторые браузеры ограничивают localStorage для file://: при ошибке хранения редактор покажет «Не сохранено». Используйте экспорт JSON.

## Разработка
Установите Node.js 22+ и выполните в корне проекта:

```bash
npm install
npm run dev
```

Откройте адрес, который напечатает Vite. Для production: `npm run build` (результат `dist/`), затем `npm run preview`. Для обновления автономного HTML: `npm run build:offline`. Скрипты predev и prebuild автоматически обновляют шаблон экспорта.

## Структура
- `src/App.js` — компоновка, реактивное состояние, сохранение, импорт/экспорт, порядок блоков.
- `src/model.js` — модель курса, шаблоны всех 10 модулей, нормализация старых JSON, валидация, безопасное форматирование.
- `src/components/ModuleView.js` — отображение учебных модулей и интерактивные ответы.
- `src/components/ModuleEditor.js` — настройки каждого типа.
- `src/components/Fields.js` — переиспользуемые поля, медиа-загрузка и форматирование.
- `src/style.css` — стили и адаптивность.
- `scripts/build-offline.mjs` — сборка автономной страницы из тех же исходников.
- `vendor/vue.global.js` — Vue 3.5.13 (MIT), для офлайн-сборки.

## Возможности и ограничения
10 типов модулей, перетаскивание, перемещение стрелками, дублирование, скрытие, удаление, предпросмотр, импорт/экспорт JSON, HTML-экспорт учебной страницы, проверка вопросов. Формат JSON совместим с предыдущей версией конструктора; импортируйте старый JSON вручную, если браузер не видит старое хранилище.

Правильные ответы присутствуют в клиентском HTML, поэтому это не защищённая система экзаменации. Нет авторизации, LMS, базы данных и серверного сохранения результатов. Файлы медиа встраиваются в JSON/HTML; крупные файлы могут превысить квоту LocalStorage. Используйте ссылки или экспорт JSON.

Проверено в Chromium через загрузку HTML в тестовую страницу: отображение 10 модулей, открытие настроек каждого типа, изменение текста, добавление/копирование/перемещение/удаление, карусель, маппинг, табы, спойлер, оба типа вопросов, подсчёт результата и экспорт страницы обучающегося. Прямой переход file:// и локальный сервер были ограничены средой, поэтому постоянное сохранение и Vite/npm-сборка не проверены. Внешнее видео не проверялось.
