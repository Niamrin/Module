# Конструктор курса — Vue 3

Версия 2.0.0. Vue 3.5.13, Composition API, JavaScript, Vite. Однофайловые компоненты Vue (.vue), без UI-библиотеки, без серверной части.

## Быстрый запуск
Откройте `public/course_builder_vue3.html` в современном браузере. Vue встроен в файл; интернет для самого редактора не нужен. Для внешних изображений и видео нужен доступ к соответствующему источнику. Некоторые браузеры ограничивают localStorage для file://: при ошибке хранения редактор покажет «Не сохранено». Используйте экспорт JSON.

## Экспорт урока
Кнопка **HTML ↓** сохраняет страницу ученика. Один HTML-файл содержит видимые модули, стили, код просмотра и загруженные в курс медиа. Название вкладки браузера берётся из названия курса. Вложенные тесты, табы и интерактивные области работают при открытии файла с диска. Для медиа по внешним ссылкам требуется сеть.

Для дальнейшего редактирования сохраните курс кнопкой **JSON ↓**. В JSON входят и скрытые модули.

## История изменений
В редакторе кнопки «Отменить» и «Повторить» работают для всего курса, включая вложенные модули. В меню «История» можно перейти к выбранному состоянию. Сочетания клавиш: Ctrl/⌘ + Z для отмены и Ctrl/⌘ + Shift + Z для повтора.

История действует до перезагрузки страницы и хранит до 50 шагов отмены. Для крупных курсов с вложенными медиа количество шагов может быть меньше. Выбранное состояние курса сохраняется автоматически.

## Разработка
Установите Node.js 22+ и выполните в корне проекта:

```bash
npm install
npm run dev
```

Откройте адрес, который напечатает Vite. Для production: `npm run build` (результат `dist/`), затем `npm run preview`. Для обновления автономного HTML: `npm run build:offline`. Скрипты predev и prebuild автоматически обновляют шаблон экспорта.

## Структура
- `src/App.vue` — компоновка, реактивное состояние, сохранение, импорт/экспорт, порядок блоков.
- `src/model.js` — модель курса, шаблоны всех 9 модулей, нормализация старых JSON, валидация, безопасное форматирование.
- `src/components/modules/` — для каждого типа своя папка с компонентами просмотра и настроек. Пары зарегистрированы в `index.js`.
- `src/components/ModuleView.vue` — отображение учебных модулей и интерактивные ответы.
- `src/components/ModuleEditor.vue` — настройки каждого типа.
- `src/components/{Field,RichField,MediaField,SubCard}.vue` — переиспользуемые поля, медиа-загрузка и форматирование.
- `src/style.css` — стили и адаптивность.
- `scripts/build-offline.mjs` — сборка автономной страницы из тех же исходников.
- `src/components/modules/quiz/QuizView.vue` — прохождение теста, таймер и подсчёт результатов.

## Возможности и ограничения
9 типов модулей, перетаскивание, перемещение стрелками, дублирование, скрытие, удаление, предпросмотр, импорт/экспорт JSON, HTML-экспорт учебной страницы, проверка вопросов. Формат JSON совместим с предыдущей версией конструктора; импортируйте старый JSON вручную, если браузер не видит старое хранилище.

Правильные ответы присутствуют в клиентском HTML, поэтому это не защищённая система экзаменации. Нет авторизации, LMS, базы данных и серверного сохранения результатов. Файлы медиа встраиваются в JSON/HTML; крупные файлы могут превысить квоту LocalStorage. Используйте ссылки или экспорт JSON.
